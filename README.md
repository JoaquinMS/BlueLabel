# BlueLabel
  Grupo conformado para la signatura "Desarrollo de software" con objetivo de realizar el proyecto integrador basado en "El Buen Sabor". Guardando en este repositorio los commit mediante vayamos avanzando en el proyecto. Nos centraremos en el mercado a ventas de calzados deportivos femeninos y masculinos, dando a conocer informacion de cada producto y especificaciones acompañadas con imagenes ilustrativas.
  Reforzando el interes hacia un publico nacional, asi poder abastecer stock a todo el pais con el apoyo de un sistema conectado en cada local distribuidos en provincias. Logrando convenios con distintos expresos de encomiendas, pudiendo realizar descuentos y envios gratis, dependiendo de la cantidad y el monto de compra que se realice.
